## 2. Faithfulness of the cited Lean theorems

### Kit

**`Paper.L01.L01_main` (`pv_work/L01.lean:33`): faithful.**
- Printed: "For every $x\in\mathbb R^n$, $F_n$ is nondecreasing, and $nF_n(t)\in\{0,1,\dots,n\}$ for every $t$".
  The definition holds "for $n\ge1$".
- Lean: `theorem L01_main {n : ℕ} (hn : 1 ≤ n) (x : Fin n → ℝ) : Conclusion x`, where
  `mono : Monotone (edf x)` and
  `values : ∀ t, ∃ k : ℕ, k ∈ Finset.range (n + 1) ∧ (n : ℝ) * edf x t = (k : ℝ)`.
- Definitions: `edf x t = (1/n) * #{i : x i ≤ t}` matches Def. 2.1 exactly. `1 ≤ n` is the definition's own
  $n\ge1$.

**`Paper.P01.P01_main` (`pv_work/P01.lean:18`): weaker, disclosed.**
- Printed: "If $X_1,X_2,\dots$ are independent and identically distributed, then $D_n\to0$ almost surely."
- Lean: `theorem P01_main.{u} (hGC : GlivenkoCantelli.{u}) (Ω : Type u) [MeasurableSpace Ω] (P : Measure Ω)
  (X : ℕ → Ω → ℝ) (h : IsIIDSeq P X) : ∀ᵐ ω ∂P, Tendsto (fun n => Dn P X n ω) atTop (𝓝 0)`.
- Definitions:
  - `IsIIDSeq` = probability measure, measurable `X k`, `iIndepFun X P` and `IdentDistrib (X k) (X 0)`. This matches.
  - `Dn` = `⨆ t, |edfRV X n ω t - P.real {X 0 ≤ t}|`. This matches; the family is bounded, so the real `⨆` is the
    true supremum.
- The extra hypothesis `GlivenkoCantelli` is `∀ Ω P X, IsIIDSeq P X → GCConclusion P X`, which is the proposition
  itself, universally quantified. The Lean proof is therefore an instantiation and checks nothing beyond the
  statement's encoding.
- Disclosure is explicit: CONDITIONAL, and `AUTHOR_REPORT` §1.4 says "the Glivenko–Cantelli parameter equals P01's
  own conclusion (goal-shaped)". This matches what the key expects, but it is not a faithful Lean proof of 2.2.

**`Paper.T01.T01` (`pv_work/T01.lean:436`): weaker, disclosed.**
- Printed: "$\sqrt n D_n$ converges in distribution to $\sup_{0\le u\le1}|B(u)|$ … The limit has the distribution
  function $K(z)=1-2\sum_{k\ge1}(-1)^{k-1}e^{-2k^2z^2}$ for $z>0$."
- Lean: `theorem T01 (hDon : DonskerUniformSup) (hKol : KolmogorovFormula) {Ω : Type} [MeasurableSpace Ω]
  (P : Measure Ω) [IsProbabilityMeasure P] (X : ℕ → Ω → ℝ) (hmeas : ∀ k, Measurable (X k))
  (hind : iIndepFun X P) (hid : ∀ k, P.map (X k) = P.map (X 0)) (hF : Continuous (cdfOf P X)) : KSConclusion P X`.
- `KSConclusion` has two clauses, each for every `B` with `IsBrownianBridge Q B`:
  - `conv`: `ConvInDist P (fun n ω => √n * Dn P X n ω) Q (supAbs B)`;
  - `cdf`: `∀ z > 0, Q.real {supAbs B ≤ z} = Kfun z`.
- Definitions, which I checked by hand:
  - `IsBrownianBridge`: measurable coordinates, continuous paths on $[0,1]$, and every linear combination of
    coordinates has law `gaussianReal 0 (∑∑ a_i a_j (min u_i u_j − u_i u_j))`. This is the standard Brownian bridge,
    and one exists (e.g. $W(t)-tW(1)$), so the clauses are not vacuous.
  - `ConvInDist`: convergence of $\int f$ for every bounded continuous $f$. This is standard weak convergence, and
    S1 proves that `Dn` is measurable.
  - `supAbs` is the real `⨆` over `Icc 0 1`.
  - `Kfun` uses `∑' k, (-1)^k e^{-2(k+1)^2 z^2}`, which is the paper's series re-indexed.
- Why it is weaker:
  - There are two extra hypotheses. `KolmogorovFormula` is verbatim the `cdf` clause, so that clause is assumed, not
    checked.
  - `DonskerUniformSup` is the `conv` clause for uniform samples. The real Lean content is the reduction from a
    continuous $F$ to the uniform case (S2–S4, which compile) and the measurability of $D_n$ (S1).
  - `Ω : Type` (universe 0) is a slight narrowing, disclosed in `AUTHOR_REPORT` §7.
- Disclosed: yes. The verdict is CONDITIONAL with both inputs named.
- No counterexample files (there are no issues).
