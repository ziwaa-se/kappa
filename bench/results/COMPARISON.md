# v1.2.1 versus v1.3 on the benchmark paper: two runs each (2026-09-30)

**Paper:** `bench/paper/main.tex`, three numbered results:
- 2.1, an easy lemma;
- 2.2, a proposition resting on a cited inequality;
- 2.3, a lemma with a **planted error** (it is false for x < −1).

The answer key is in `bench/ANSWER_KEY.md`.

**Runs:** two runs per kit, all with the same unattended prompt, Lean 4.19.0 + Mathlib `c44e0c8e`, and the same machine.
- **v1.2.1:** unchanged, with one coordinator session on Opus and every role on Opus.
- **v1.3:** the driver `pv_drive.sh` with a Sonnet coordinator; each role runs on the model in its definition.

Costs are list-price estimates from the transcripts (`pv_usage.py`). For every run they agree to the cent with the cost that the Claude Code CLI reported.

## Headline

| | v1.2.1 (2 runs) | v1.3 (2 runs) | Change (means) |
|---|---:|---:|---:|
| Cost for the 3 verdicts | $71.15, $65.04 (mean $68.09) | $17.73, $13.68 (mean $15.70) | **−77% (4.3× cheaper)** |
| Tokens processed | 73.2 M, 64.1 M | 31.2 M, 21.9 M | −61% |
| Run time (sum of sessions) | 84, 83 min | 51, 30 min | −51% |
| Verdicts matching the answer key | 3/3, 3/3 | 3/3, 3/3 | same |
| Planted error caught (`ERROR`, Lean counterexample, review `COUNTEREXAMPLE VALID`) | yes, yes | yes, yes | same |
| False alarms; unfinished | 0; 0 | 0; 0 | same |

All four runs gave the same verdicts:
- 2.1: UNCONDITIONAL;
- 2.2: CONDITIONAL on one Nesbitt parameter of provenance (i);
- 2.3: ISSUE, classified `ERROR`.

**The difference is stable.** The cheaper v1.2.1 run costs 3.7× the dearer v1.3 run.

## Where the saving comes from

**The same task on the same model (Opus in both kits).** These are the reviewing roles. Their saving comes from the structural changes, not from cheaper models: rule cards instead of reading all the rules, the scripted mechanical audit, and shorter outputs.

| Task (Opus in both) | v1.2.1 run 1 / run 2 | v1.3 run 1 / run 2 |
|---|---:|---:|
| Final audit, Lemma 2.1 | $3.29 / $4.26 | $0.63 / $0.59 |
| Final audit, Proposition 2.2 | $4.52 / $3.70 | $1.00 / $1.55 |
| Counterexample review, Lemma 2.3 | $2.26 / $3.05 | $1.44 / $1.30 |
| Statement gates, the 3 results | $7.00 / $7.28 | $3.62 / $2.91 |
| Issue ruling, Lemma 2.3 | $1.35 / $2.01 | $0.93 / $1.06 |
| **Sum of these tasks** | **$18.42 / $20.30** | **$7.62 / $7.41** |

On these same-model tasks v1.3 is 2.4–2.7× cheaper. Two items are not in the table:
- the gap-file final audit of Lemma 2.3 (v1.2.1: $3.64 / $5.35; v1.3: $0.96 / none, see "Other differences" below);
- reconnection audits (v1.2.1 only).

**Roles moved to Sonnet**, whose work is checked afterwards by the Opus gate and auditor:

|---|---:|---:|

## Interruptions (disclosed)

| Run | Interruption | Effect |
|---|---|---|
| v1.2.1 run 1 | Headless Claude Code stopped a background audit 600 s after the coordinator ended its turn | Resumed with `/pv-resume`; the restart cost $5.86. v1.3 now guards against this |
| v1.2.1 run 2 | The account's usage limit was reached mid-run | Resumed with `/pv-resume` after the reset; the restart is included in its cost |
| v1.3 run 1 | A bug in the new driver: it stopped after the first batch | Fixed; one extra session start (≈ $1) |
| v1.3 run 2 | None | — |

Each v1.2.1 run therefore includes one restart of the coordinator. Without the restart, v1.2.1 would still cost more than three times as much as v1.3.

## Other differences between runs (allowed by the rules)

- **Lemma 2.3 in v1.3 run 2** was flagged as false at the gate. It went straight to the issue ruling and the counterexample review, with no proof attempt and no gap-file audit. The other three runs proved it modulo a gap and then audited that gap file. Both paths are allowed. This one is cheaper, and with a one-step proof it loses nothing.
- **Proposition 2.2** was drafted in parallel with 2.1 in both v1.2.1 runs. That needed a predecessor parameter and a later reconnection (prover + audit, $4.88 and $7.64). Both v1.3 runs drafted it after 2.1 had passed, and imported 2.1 directly.
- **v1.2.1 run 1 built a shared-definitions file** ($3.43); the other runs judged it unnecessary.

## Limits

- **Two runs per kit.** The gap between the kits (3.7× to 5.2× per pair of runs) is far larger than the spread within a kit. Still, two runs show stability, not a confidence interval.
- **A tiny, elementary paper.** On research papers, proving and auditing dominate and the coordinator's context grows over dozens of results. The same mechanisms should help at least as much there, but this benchmark does not measure it.
- **The coordinator is still the largest item in v1.3** (about 30%): roughly 120–170 responses even on Sonnet. It is the next target.
- **List prices.** On a subscription plan these numbers indicate how fast the usage limit is consumed, not a bill.
